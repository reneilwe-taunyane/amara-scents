# Code Style --- Amara Scents

-   Use TypeScript.
-   Keep components focused and reusable.
-   Centralise product data/constants where appropriate.
-   Avoid giant components.
-   Avoid unnecessary abstraction and dependencies.
-   Components use PascalCase.
-   Variables/functions use camelCase.
-   Constants use descriptive names.
-   Keep responsive CSS understandable.
-   Comment why non-obvious code exists, not what obvious code does.
