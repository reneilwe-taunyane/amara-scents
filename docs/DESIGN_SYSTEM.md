# Design System --- Amara Scents

## Creative direction


Amara Scents should feel: **Feminine + bold + playful + sensual +
classy + warm + confident + contemporary.**

It is a South African brand. Communicate contemporary South African
creative energy without stereotypical African patterns, tribal graphics,
safari imagery or tourist-style motifs.

Desired feeling: a stylish South African fragrance brand with
international polish and strong personality.

## Visual principles

-   Product photography is a hero asset.
-   Use editorial compositions.
-   Use expressive colour.
-   Combine elegant serif typography with modern sans-serif UI.
-   Use asymmetry where useful.
-   Keep generous whitespace.
-   Keep shopping interactions simple.
-   Avoid generic beige luxury templates.
-   Avoid excessive gold, gradients, clutter and unnecessary animation.

## Typography

Use an elegant editorial serif for hero headings, section headings and
product names. Use a clean modern sans-serif for navigation, body copy,
prices, buttons and forms. Occasional italic serif emphasis is
encouraged.

## Photography

The user already has the actual fragrance product images. Do not
generate or download replacements. Use them in hero, collection, product
detail, cart and confirmation where appropriate.

Future editorial photography should use contemporary South African
visual energy: warm light, confident styling, natural skin texture,
modern fashion and premium fragrance contexts.

## Core components

Navigation, mobile navigation, hero, product card, product grid, product
gallery, size selector, quantity selector, buttons, inputs, modal,
toast, cart summary, checkout form, order summary, footer,
empty/loading/error states.

## Product card

Show image, name, notes, mood, size options and Add to Bag.

50 ml = R250. 100 ml = R500.

## Responsive

Mobile 390px, tablet 768px, desktop 1440px. Mobile must be intentionally
designed.

## Accessibility

Use good contrast, visible focus, clear labels, logical headings,
touch-friendly controls and clear errors. Do not communicate state by
colour alone.
