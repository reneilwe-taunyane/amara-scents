# Application Flow --- Amara Scents

1.  Home: introduce brand and featured fragrances.
2.  Shop: browse all 9 fragrances.
3.  Product: view image, notes, mood, description and select size.
4.  Add to Bag: add selected variant.
5.  Cart: adjust quantity, remove items, review totals.
6.  Google authentication: sign in.
7.  Checkout: enter customer/delivery information.
8.  Place order: validate and persist in Supabase.
9.  Confirmation: show successful order.
10. Email: Resend sends confirmation.

Optional newsletter/discount popup must never block the required
journey.
